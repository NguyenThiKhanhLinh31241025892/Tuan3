HƯỚNG DẪN NỘP BÀI CSS - TUẦN 3

1. Đường dẫn trên GitHub: Tuan3/VeNha/
2. Đổi thông tin trong index.html: tên, MSSV, lớp, GitHub, Facebook và email.
3. Ảnh cá nhân: lưu tên "anh-ca-nhan.jpg" trong thư mục assets/ (thay ảnh mẫu tự động).
4. Mở index.html để kiểm tra tất cả các liên kết.
5. Font Awesome sử dụng CDN. Cần có Internet khi xem BaiTap9.html và index.html để icon hiển thị.
6. Không tải file ZIP lên GitHub khi nộp. Hãy tải lên TỪNG FILE và các thư mục giữ đúng cấu trúc.
7. Bài 3 của đề là một lựa chọn: lab CSS hoặc các bài 4,5,6,7; đã có các bài 4-7.
8. Các tài nguyên cho bài 8 được đặt tại css1/css1.html và css2/css2.html.
